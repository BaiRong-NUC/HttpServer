如何启动项目

在项目根目录执行以下命令以构建项目（复制粘贴即可）： 

mkdir -p build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j
# 或者：
./rebuild.sh

使用示例脚本快速启动 / 停止服务器：

./app/loop.sh start
./app/loop.sh stop

更多信息请查看项目根目录的 README.md;也可使用 server_api.sh 和 client_api.sh 进行 TcpServer API 测试。
