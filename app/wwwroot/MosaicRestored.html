基于 C++ 代理层与 Python CodeFormer 服务的马赛克去除体验页。上传图片后，前端会将原图发送到 /api/restore，由后端完成增强、修复和结果回传。

处理链路 Browser → C++ → FastAPI → Replicate
默认模型 CodeFormer Face Restoration
结果输出 预览、下载、外链回显

使用说明

  1. 上传待修复图片，支持拖拽和点击选择。
  2. 调整放大倍数、保真度和增强选项。
  3. 点击开始修复，等待结果图返回并下载。
接口参数

upscale / face_upsample / background_enhance / codeformer_fidelity

返回头

X-Output-Url / X-Replicate-Output-Url

建议

人脸图像优先，图片越清晰越容易获得稳定结果。
